Fimara Complete System Documentation

Production Specification, Architectural Blueprints & User Manual

Fimara Financial Manager

Version: 1.6.5 Runtime: React 19 · Node 22 · TypeScript · Vite Platforms: PWA · Android TWA · Web Desktop & Mobile Status: Production Verified

1. Executive Summary & Vision

Fimara is an institutional-grade, privacy-first personal and entity financial management platform. Engineered to mirror the resilience, security, and fluid user experience of tier-1 private wealth applications (such as Ecobank Private Wealth, Revolut, and Monzo), Fimara eliminates the common pitfalls of modern cloud fintech apps: network fragility, privacy invasion, and slow manual data entry.

The 5 Core Pillars of Fimara:
  • 100% Offline-First Ledger: Complete operations with zero network requirement. Optimistic mutations automatically reconcile upon reconnection.
  • Bank-Grade Security: Configurable inactivity screen locks, WebAuthn biometrics (Touch/Face ID), 4-digit PBKDF2 local passcode, and background App Switcher privacy veil.
  • Smart Budget Velocity Analytics: Replaces static budget bars with daily burn rate calculations, calendar progress pacer, and 80% threshold warnings.
  • Frictionless Ingestion: Built-in MoMo SMS auto-parser and receipt OCR vision parser to log expenses in seconds.
  • Pan-African & Global Rails: Paystack integration (Ghana & Nigeria mobile money and banks) with real-time multi-currency forex revaluation (GHS, USD, EUR, GBP, NGN).

2. System Architecture & Tech Stack

Front-End Client

  • Framework: React 19 with strict TypeScript (5.8.2) and Vite (6.2.3).
  • Styling System: Tailwind CSS v4, custom foundation design tokens with strict dark/light palette variables and glassmorphism.
  • Iconography & Motion: Lucide React icons, Framer Motion transitions, HTML5 Haptics.
  • Data Visualization: Recharts graphs and KaTeX mathematical formatting.
  • PWA / Mobile: Service Worker caching, Web App Manifest, Android Trusted Web Activity (TWA) Digital Asset Links.

Back-End Server

  • Runtime: Node.js (v22+), Express 4.21, TypeScript via tsx, production bundled via esbuild.
  • Real-Time Engine: WebSocket Server (ws) for bidirectional low-latency AI advisor spoken audio streams.
  • Dual Database Engine: Primary MongoDB Atlas cluster with automatic, zero-config in-memory fallback for local development.
  • Third-Party Integrations: Google Gemini 2.0/2.4 Flash & Live Audio, Paystack API with HMAC-SHA512 verified webhooks, and Nodemailer SMTP email service.

3. Bank-Grade Security, Auth & Privacy

Fimara employs a multi-tiered security perimeter designed to protect financial privacy on shared or mobile devices:

Security Mechanism Implementation Details User Experience Benefit
Configurable Auto-Lock Inactivity timers: Immediate, 1m, 5m, 15m, 30m, Never. Handled in src/services/sessionLock.ts. Locks screen without logging out or discarding active form drafts. Quick biometric/PIN re-auth.
App Switcher Privacy Shield Listens to visibilitychange and window blur. Applies a frosted glass veil. Prevents screen previewers and OS task switchers from capturing sensitive balance snapshots.
4-Digit Offline Passcode PBKDF2/SHA-256 hashed passcode stored locally with automated email confirmation. Enables safe local ledger inspection when offline without entering main account password.
WebAuthn Biometrics W3C Web Authentication credentials (Face ID, Touch ID, Windows Hello). Instant, passwordless local authentication.
HTTP-Only Cookie Sessions Cryptographically signed JWT stored in HttpOnly, SameSite=Lax, Secure cookies. Completely immune to cross-site scripting (XSS) token theft.

4. Offline-First Resilience & Mutation Sync

Fimara ensures that financial records can be created and reviewed anytime. When internet is unavailable, all operations are enqueued in offline_mutations_v1 inside localStorage and reflected immediately in the UI via optimistic state updates. 

// Offline Mutation Workflow
1. User taps "Save Transaction" while offline
2. queueOfflineMutation(userId, profileId, 'CREATE_TRANSACTION', payload)
3. Optimistic transaction added to local profile cache with pendingSync: true
4. UI displays haptic pulse and "Transaction recorded offline" toast
5. When navigator.onLine fires, background worker iterates queue and posts to /api/transactions
6. Queue is purged and fresh authoritative ledger is loaded

5. Multi-Profile & Multi-Currency Engine

Users can create and isolate distinct entities (e.g. Personal, Business, Family, Savings). Profiles maintain their own transactions, budgets, vaults, debts, and base currencies (GHS, USD, EUR, GBP, NGN).

  • Entity PIN Locks: Individual profiles can be protected with custom PINs for privacy on shared laptops or family tablets.
  • Exchange Rate Management: Centralized exchange rates dynamically revalue net worth and multi-currency balances.

6. Smart Budget Velocity & 80% Pacing Engine

Located in src/services/budgetVelocity.ts. Traditional budget apps only report spent vs limit. Fimara introduces calendar velocity modeling:

Burn Velocity Ratio Formula:

Burn Velocity Ratio = (Budget Spent %) / max(1, (Current Day / Days in Month) * 100)
Safe Daily Allowance = max(0, Budget Limit - Total Spent) / max(1, Days Remaining)
  • Pacing Fast Warning: When Burn Velocity ≥ 1.25, the app flags expenditure as pacing hot (e.g. 🔥 Pacing fast (1.4x)) and projects the exact day the budget will exhaust.
  • 80% Threshold Warning: Alerts the user when 80% of limit is consumed, allowing course-correction before overspending.
  • 105% Hard Lock: Automatically caps categories exceeding 105% to isolate catastrophic budget blowouts.

7. Transaction Ledger & Export System

Full-featured ledger supporting filtering by type, category, date range, and text search. Includes mobile numeric keypad optimization (inputMode="decimal") and micro-haptic feedback.

  • Client-Side Exports: Instant export of filtered transactions to formatted .csv or .xlsx spreadsheets.
  • Recurring Rules: Automatic cadence scheduling (weekly, monthly).

8. MoMo SMS & Receipt OCR Auto-Parser

Designed specifically for modern African mobile payment habits:

  • Mobile Money Ingestion: Paste SMS notifications from MTN MoMo, Telecel Cash, or AT Money to automatically extract transaction amount, reference, and recipient name into the transaction modal.
  • Receipt Photo OCR: Upload or snap a picture of physical paper receipts; Google Gemini Flash extracts total amount, date, and merchant into the ledger in 1 tap.

9. Savings Vaults & Paystack Payment Rails

Wealth accumulation engine supporting flexible goals, high-yield vaults, and locked savings safes.

  • Paystack Integration: Direct deposit from Mobile Money or cards via Paystack inline checkout. Webhooks verified with HMAC SHA-512 signatures.
  • Early Withdrawal Governance: 2% standard administrative fee, with a 10% penalty fee applied if locked vaults are broken prematurely.

10. Debt & Peer-to-Peer Lending Tracker

Bilateral tracking of liabilities (I Owe) and receivables (Owed to Me). Features partial installment settlements, due dates, and real-time net debt impact on overall net worth.

11. Gemini AI Advisor & Live Voice Consultation

Embedded financial intelligence powered by Google Gemini:

  • Context-Aware Advisor: Real-time ledger grounding provides personalized debt-snowball advice, tax breakdowns, and cashflow optimization.
  • Sliding Quota Window: 40 messages per 8 hours with cooldown counters to prevent API exhaustion.
  • Spatial Voice Orb: Full-duplex WebSocket stream (/api/gemini/live-voice) for conversational spoken audio consultations.

12. Financial Reports & Institutional PDF Statements

Comprehensive analytics dashboard with monthly cashflow bars, category breakdowns, and net worth trajectory.

  • Institutional PDF Statements: Client-side generation of formal, branded monthly statements via jspdf, complete with transaction hashes and verification timestamps suitable for visa or bank loan applications.

13. Administrative God Mode & Governance

Accessible by platform administrators to monitor health and handle vault operations:

  • Platform-wide metrics: user count, aggregate vault holdings, collected fees.
  • Withdrawal approvals: review recipient accounts and execute automated payouts.
  • Tamper-proof audit logs tracking every administrative action.

14. Core Data Schema Models

// Transaction Schema
interface Transaction {
  id: string;
  profileId: string;
  type: 'income' | 'expense';
  amount: number;
  currency: string;
  category: string;
  date: string; // YYYY-MM-DD
  note: string;
  recurring: 'none' | 'weekly' | 'monthly';
  createdAt: string;
  pendingSync?: boolean;
}

// Budget Schema
interface Budget {
  id: string;
  profileId: string;
  category: string;
  limit: number;
  currency: string;
  spent?: number;
  percentage?: number;
  remaining?: number;
  status?: 'normal' | 'exceeded_locked';
}

// Vault Goal Schema
interface Goal {
  id: string;
  profileId: string;
  name: string;
  target: number;
  current: number;
  currency: string;
  status?: 'active' | 'pending_withdrawal' | 'withdrawn' | 'locked';
  vaultType?: 'high_yield_vault' | 'locked_savings' | 'emergency_stash' | 'flexible_goal';
  createdAt: string;
}

17. Operational Runbook & FAQ

Scenario Root Cause Resolution
Biometric prompt displays "No registered profile" Device credentials not yet enrolled in browser WebAuthn registry Go to Settings > Security, tap Enable Biometrics, and scan finger or face.
Offline PIN prompt rejects entry PIN was not configured while online Sign in with email/password while online, navigate to Settings > 4-Digit Offline Passcode, and save a PIN.
